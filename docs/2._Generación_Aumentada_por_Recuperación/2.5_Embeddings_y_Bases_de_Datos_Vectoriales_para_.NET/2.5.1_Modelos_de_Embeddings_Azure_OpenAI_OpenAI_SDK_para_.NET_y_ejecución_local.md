# 2.5.1 Modelos de Embeddings (*Azure OpenAI, OpenAI SDK para .NET, y ejecución local de modelos con ONNX Runtime en C#*)

En el ecosistema de RAG, los **embeddings** actúan como el puente fundamental entre el lenguaje humano y el procesamiento matemático. En esta sección, profundizaremos en cómo implementar modelos de embeddings dentro del ecosistema .NET, evaluando desde servicios en la nube altamente escalables hasta soluciones locales para escenarios de alta privacidad o baja latencia.

### Concepto de Embedding en el contexto RAG

Un embedding es una representación numérica (vector) de un fragmento de texto. A diferencia de una búsqueda por palabras clave, los embeddings capturan el **significado semántico**. En .NET, trabajamos con estos vectores (usualmente arreglos de `float`) para comparar la similitud entre la consulta del usuario y los documentos PDF previamente procesados.

---

### 1. Azure OpenAI: Embeddings de Clase Empresarial

Para aplicaciones corporativas, Azure OpenAI es la opción preferida debido a sus certificaciones de seguridad, integración con Entra ID y alta disponibilidad.

#### Modelos recomendados:
*   **text-embedding-3-small:** Balance óptimo entre rendimiento y costo.
*   **text-embedding-3-large:** Mayor precisión con dimensiones configurables (hasta 3072).
*   **text-embedding-ada-002:** El estándar anterior, aún ampliamente utilizado.

#### Implementación en C#:
Utilizamos el paquete NuGet `Azure.AI.OpenAI`.

```csharp
using Azure;
using Azure.AI.OpenAI;

// Configuración del cliente
var endpoint = new Uri("https://tu-recurso.openai.azure.com/");
var credentials = new AzureKeyCredential("tu-api-key");
var client = new OpenAIClient(endpoint, credentials);

// Configuración de las opciones
var embeddingOptions = new EmbeddingsOptions(
    deploymentName: "text-embedding-3-small", 
    input: new[] { "El procesamiento de documentos PDF requiere precisión." }
);

// Obtención de vectores
Response<Embeddings> response = await client.GetEmbeddingsAsync(embeddingOptions);

foreach (var item in response.Value.Data)
{
    ReadOnlyMemory<float> vector = item.Embedding;
    Console.WriteLine($"Dimensiones del vector: {vector.Length}");
}
```

---

### 2. OpenAI SDK para .NET

Si tu arquitectura no reside en Azure o prefieres utilizar directamente la API de OpenAI, el SDK oficial para .NET (`OpenAI`) proporciona una interfaz similar pero simplificada para el acceso global.

#### Ejemplo de uso:
```csharp
using OpenAI.Embeddings;

EmbeddingClient client = new("text-embedding-3-small", "tu-api-key");

string text = "Aprendiendo RAG con .NET 8";
OpenAIEmbedding embedding = client.GenerateEmbedding(text);

ReadOnlyMemory<float> vector = embedding.ToFloats();
```

**Nota técnica:** Al trabajar con modelos como `text-embedding-3-large`, puedes reducir las dimensiones del vector para ahorrar espacio en la base de datos vectorial (visto en la sección 2.5.2) sin perder significativamente la precisión semántica, gracias a una técnica llamada *Matryoshka Embeddings*.

### 3. Ejecución local con ONNX Runtime en C#

Existen escenarios donde la privacidad de los datos contenidos en los PDF es crítica, o donde el costo de las llamadas a la API es prohibitivo. En estos casos, podemos ejecutar modelos de embeddings (como los de la familia BERT o RoBERTa) localmente utilizando **ONNX Runtime**.

#### Ventajas de la ejecución local:
*   **Cero latencia de red:** Ideal para aplicaciones de escritorio o procesamiento masivo.
*   **Privacidad total:** Los datos nunca abandonan la infraestructura del cliente.
*   **Costo:** Solo el uso de cómputo (CPU/GPU).

#### Flujo de implementación:
Para usar un modelo local (por ejemplo, `all-MiniLM-L6-v2`), necesitamos el archivo `.onnx` del modelo y el vocabulario para la tokenización.

Podemos utilizar la librería `Microsoft.ML.OnnxRuntime` junto con un tokenizador compatible (como `Microsoft.ML.Tokenizers`).

```csharp
using Microsoft.ML.OnnxRuntime;
using Microsoft.ML.OnnxRuntime.Tensors;

// 1. Cargar el modelo ONNX
using var session = new InferenceSession("models/all-minilm-l6-v2.onnx");

// 2. Preparar los inputs (simplificado: asumiendo tokenización previa)
// El modelo espera input_ids, attention_mask y token_type_ids
long[] inputIds = { 101, 2023, 2003, 102 }; // Tokens para "[CLS] hello world [SEP]"
var inputTensor = new DenseTensor<long>(inputIds, new[] { 1, inputIds.Length });

var inputs = new List<NamedOnnxValue>
{
    NamedOnnxValue.CreateFromTensor("input_ids", inputTensor),
    // Se deben incluir los demás tensores requeridos por el modelo
};

// 3. Ejecutar inferencia
using IDisposableReadOnlyCollection<DisposableNamedOnnxValue> results = session.Run(inputs);

// 4. Extraer el vector (normalmente del nodo 'last_hidden_state' o 'sentence_embedding')
var output = results.First().AsEnumerable<float>().ToArray();
```

### Consideraciones al elegir el modelo de Embedding

| Característica | Azure OpenAI / OpenAI | Local (ONNX) |
| :--- | :--- | :--- |
| **Facilidad de uso** | Alta (API gestionada) | Media (Requiere gestión de modelos) |
| **Costo** | Pago por token | Gratis (Costo de CPU/GPU) |
| **Dimensiones** | 1536 - 3072 | Usualmente 384 - 768 |
| **Escalabilidad** | Elástica | Limitada al hardware local |
| **Privacidad** | Nivel Corporativo (SOC2/HIPAA) | Máxima (Sin salida de red) |
